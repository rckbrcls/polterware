# Upstream component index (fluid-functionalism) -> Polterware

Pinned to commit `1add7762eea3b5bbb3a1f44bea296e13c3f119c0` (MIT). Use this to find the exact source and behavior before
porting. Read the matching section of `upstream-craft.md` for values and reasons; fetch the
raw source when you need the mechanism. Sources are React + framer-motion + Radix (and a Base UI
flavor); translate with `solid-motion-recipes.md`.

- Source (GitHub): `https://github.com/mickadesign/fluid-functionalism/blob/1add7762eea3b5bbb3a1f44bea296e13c3f119c0/<path>`

- shadcn registry JSON: `https://www.fluidfunctionalism.com/r/<registry-name>.json` (Base UI flavor: `https://www.fluidfunctionalism.com/r/base/<registry-name>.json`)
- Guidelines: `motion-guidelines.md`, `component-documentation-guidelines.md`, `preset-guidelines.md`
- Upstream skill: `skills/fluid-functionalism/{SKILL.md,references/{components,craft,custom-motion,stack-audit}.md}`

Tier legend: fast 0.08s, moderate 0.16s (critically damped), slow 0.24s bounce 0.12.
Priority hint for Polterware work: Tabs, Dropdown/Popover/Tooltip, Table + lists (fluid hover),
Sidebar, Dialog/Drawer, Button press, then Accordion/collapses.
